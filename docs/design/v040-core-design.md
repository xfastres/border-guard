# 《边境守卫 v0.40》1 页纸核心玩法设计稿（最小好玩版 MVP）

> **设计原则**：核心骨架一次定死，具体内容分阶段往上加；只保留「能直接产生爽感与策略选择」的系统，砍掉一切增加理解负担但没有正反馈的惩罚规则。
> **文档定位**：阶段 1（设计稿），经确认后作为阶段 2 新建独立文件 `Border-Guard-v0.40.html`（不覆盖 `Border-Guard-v0.32.html`）的唯一实现依据。

---

## 一、核心定位：双玩法如何「融合而不臃肿」？

很多玩家既喜欢**白天经营城池滚雪球**，又喜欢**夜晚塔防+领主动作守家**。二者不冲突，关键在于**昼夜职责彻底分离、经营零繁琐微操**：

- **白天（轻城建 · 实时经济）**：保留**居民、资源开发、实时产出、扩地、城墙防御布局**；**砍掉繁琐微操**（建好场子自动派空闲居民去干活，不用手动一个个指派；每 5 秒肉眼可见飘字涨资源）。
- **夜晚（爽塔防 · 动作收割）**：保留**五夜波次守城**；**补足战斗深度与手感**（3 种互补防御塔 + 4 种差异化敌兵 + 领主主动技能 + 击杀即时爆金币 + 战后肉鸽质变三选一）。

**昼夜正循环**：白天实时产资源建厂扩地摆塔 → 夜晚多种塔配合领主放技能爽快清怪爆金币 → 战后选质变卡牌 → 下一天城池更强、火力更猛。

## 二、MVP 明确的「做减法」清单（先砍掉 / 后置）

为了在 60 秒内让玩家彻底玩懂并上头，v0.40 MVP 坚决去掉以下拖慢节奏的系统：

| 原系统 | v0.40 处理方式 | 原因 |
|---|---|---|
| 开局 A/B 跑图选址 | **砍掉**，开局直接落地规整主城 | 跳过前 1 分钟枯燥跑图，开局 5 秒进入建造与决策 |
| 白天 7 次行动点硬限制 | **砍掉**，只以资源余额约束建造 | 玩家有资源就该能建，不再出现「有钱有材料但没行动只能干等」 |
| 野外远征营地（维护/停产/双线/营救） | **后置**（核心好玩后再考虑以新模式回归） | 规则链过长、惩罚过重，严重分散主城守卫注意力 |
| 军令 + 4 种遗迹 + 稀缺资源 | **后置** | 引导成本高且与主城核心循环割裂 |
| 城内随机杂树 / 碎石 / 假麦田 | **彻底清理** | 杜绝误导与“树上长塔 / 资源堵门”问题 |

## 三、城内地图与建造规则（彻底修正 v0.32 布局缺陷）

主城开局即拥有规整的 `5×5` 整圈城墙与 4 扇城门，空间按**「内圈生产 · 十字门道 · 外圈防线」**清晰分区：

```text
  [ 草地 ]  [ 草地 ]  [ 北门 ]  [ 草地 ]  [ 草地 ]
  [ 塔位 ]  [ 粮田 ]  [ 空地 ]  [ 林地 ]  [ 塔位 ]
  [ 西门 ]  [ 道路 ]  [ 主城 ]  [ 道路 ]  [ 东门 ]
  [ 塔位 ]  [ 石脉 ]  [ 空地 ]  [ 金矿 ]  [ 塔位 ]
  [ 草地 ]  [ 草地 ]  [ 南门 ]  [ 草地 ]  [ 草地 ]
```

- **建造地形铁律**：**严禁在森林（树）、岩石（山）、道路、水域与城门正后格上建塔**；选中建筑时地图只高亮合法草地格。
- **城内无假杂物**：起始 `5×5` 内只保留主城、道路、4 个可开发资源点（粮/木/石/金）与干净草地，居民从主城走 1 步即可开工，西/东/南/北墙内侧一整圈皆为干净塔位。
- **自由扩地**：白天可花金币点击城墙外相邻陆地直接推墙扩建（自动重算整圈城墙，保留当前耐久比例），向外圈进更多野外高产资源（富金矿 / 铁矿）和纵深塔位。

## 四、白天：实时经济与轻松经营（75 秒倒计时，随时可点「立即开战」）

- **3 种清晰资源**：**金币**（建塔/升级/扩地/招人）、**材料**（开发资源/建塔/修墙）、**粮食**（招募居民、解锁人口上限，**无扣粮饿死/停产惩罚**）。
- **白天实时跳产出（每 5 秒结算一次，头顶飘字直接入账）**：
  - 农场（产粮食）、林场/采石场（产材料）、金矿（产金币）。
  - 建成后**自动从主城空闲居民中分配工人**（无需逐个点建筑派人）；有工人在岗产出直接翻倍，也可在主城一键招募新居民或转职（工匠提产 / 守卫夜间协防）。
  - 玩家看着倒计时和每 5 秒跳动的资源，可以自然决策「再等 5 秒凑够材料补一座冰塔，然后立刻点开战」。
- **白天免费修墙体验优化**：点底部「加固城防」即可按现有材料一键全修或部分修墙，不用进多层菜单。

## 五、夜晚：多塔配合 + 领主动作 + 肉鸽质变（共 5 夜）

### 1. 三种互补防御塔（均可升级至 2 级）
| 塔型 | 定位 | 特色 |
|---|---|---|
| **箭塔** | 便宜、高射速单体 | 专杀高速怪与远程射手，2 级提升射程与连射 |
| **火炮塔** | 范围爆炸 AOE | 对聚集拆墙的怪群造成溅射伤害，专克怪海 |
| **寒冰塔** | 大范围控场减速 | 命中使区域敌人减速 `45%` 持续 `2.5s`，大幅放大炮塔与箭塔输出 |

### 2. 领主手感与主动技能
- **基础战斗**：`WASD` / 点地移动，自动或空格挥斩（近战弧形范围伤），内置 `0.25s` 受击无敌帧防止同帧暴毙。
- **Q · 旋风重斩**（冷却 `7s`）：360° 范围高伤 + 击退周围敌人，专救快破的城墙。
- **E · 战术冲刺**（冷却 `6s`）：向移动/鼠标方向快速突进一段距离并获得短暂护盾，轻松切城外远程怪或支援另一侧城门。
- **R · 号令齐射**（每夜 `1` 次）：所有防御塔与守卫立刻触发一次强化齐射，关键时刻逆转战局。

### 3. 五夜波次与敌人变化（清晰预告）
- **第 1 夜（西侧）**：哥布林步兵 + 少量疾风狼骑（教玩家用箭塔/领主挡门）。
- **第 2 夜（东侧，白天提前红标预告）**：步兵 + 疾风狼骑 + 荒原弓手（引入远程威胁，鼓励领主冲刺切后排或建炮塔）。
- **第 3 夜（东西双路）**：加入**铁甲破城锤**（高血高拆墙伤害，冰塔减速 + 箭塔集火最佳）。
- **第 4 夜（三路高压）**：全兵种混编大波次，检验城防布局与卡牌流派成型度。
- **第 5 夜（首领终战）**：**裂城统领**登场（周期红圈蓄力重砸城墙 + 召唤随从），击退即通关。
- **即时反馈**：每击杀一只怪立刻爆金币飘字入账；清完当夜立刻弹出**肉鸽三选一**！

### 4. 肉鸽三选一卡牌（8 张质变强化，告别纯加小数值）
1. **连珠箭雨**：所有箭塔攻击变为双发连射（单发 65% 伤害，总伤 +30% 且清杂更爽）。
2. **熔岩炮弹**：火炮塔爆炸留下 `3s` 灼烧焦土，持续烫伤经过的敌人。
3. **深寒碎冰**：被寒冰塔减速的敌人受到的所有伤害 `+30%`。
4. **血战旋风**：领主 `Q` 旋风重斩每命中 1 名敌人回复 `5` 点生命。
5. **迅捷统帅**：领主移速 `+25%`，`E` 冲刺冷却减少 `2s`。
6. **工匠值守**：白天与夜晚每 `5s` 由在岗工匠自动修补主城城墙 `+18` 耐久。
7. **全城皆兵**：主城所有居民在夜间都会从城墙发射协防箭矢（不再只有守卫才打怪）。
8. **赏金号角**：击杀重甲兵与远程弓手额外掉落双倍金币，并立即获得 `+12` 金币。
