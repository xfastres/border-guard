开发基线为 `004247bb1db7f564cc5bc4994d49bef4aad1c387`，分支为 `feat/v060-gameplay-balance-overhaul`。

## 玩家可以直接检查的变化

| 入口 | 观察与操作 |
| --- | --- |
| 备战 | 四张商品卡、构筑属性、穿戴和背包同屏。点击详情或按 C 打开居中角色详情，Esc 返回。背包纵向容纳图标、可换行装备名和槽位，横向滚动浏览剩余物品。 |
| 常驻工具栏 | 商店、背包、天命、转移和情报各有一个图标。备战时前两个定位对应区域，战斗中可只读查看。天命、转移和情报各自打开弹窗。 |
| 天命宝匣 | 最低匣价常驻，另外两件从既有价格中抽取。免费换一批只更换货架，购买一次即调用原子开奖。购买前显示空劫概率，开出奖励后三选一。自定价格保留原投入范围，W29 的截止时间适用。 |
| 开局、结算与存档 | 近期波次记录可以展开。结算显示奖励到账或待保存，内部标识只保存在存档中。存档备份按钮直接下载 JSON。 |
| 战斗 | 飞刃绕身、贯刃直刺、风弧拖尾、烈焰热浪、冰晶碎裂、雷柱折线、血色虹吸、重锤震环、圣系阵纹各有轮廓。主印的 1／3／5 星分别增强发射纹、内圈和弹道。暴击与精英击杀带方向性微震，斩杀金字描边。蓄力线箭头、重击危险外圈和终局安全区在低特效档仍保留。 |

额外修正包括金币更新后回退到 Emoji、非火冰联动误标、悬停提示延迟、聚焦按钮时回车被开波快捷键抢占，以及备用导出提示玩家使用开发者控制台。

## 性能与验证

| 特效档 | 粒子 | 法阵 | 残影 | 每次更新最多新粒子 |
| --- | ---: | ---: | ---: | ---: |
| 精致 | 192 | 32 | 14 | 36 |
| 轻量 | 64 | 12 | 5 | 12 |
| 精简 | 0 | 0 | 0 | 0 |

装饰对象循环复用。自动档于同屏敌人列表达到 112 个或低于 43 FPS 时降至轻量，持续低于 29 FPS 可再降一级。切档间隔至少 1.1 秒，微震间隔至少 130 毫秒。地纹复用图案，轻量与精简档缓存最多 32 个普通敌人造型。

- 306 项单元、27 项集成、3 项独立架构门禁通过（架构门禁已计入单元总数）。本机用 Node 附带的 Acorn 为原架构断言提供 AST。
- 105 个固定种子对局的逐行记录与先前校准版本字节相同。天命专项另行验证免费刷新、旧按钮、连点、开空、中奖、唯一领取及 W29 截止。
- 原生软件 Canvas 压测使用真实渲染器，每波放入 145 个敌人并强制光栅化 70 帧。1440×900、W25–W30 轻量档各波 P95 为 17.55、17.29、17.24、16.18、14.35、18.86 毫秒。W30 的 1920×1080 为 30.84 毫秒，390×844 为 10.44 毫秒。这些值只覆盖绘制，不含浏览器布局、输入或整帧调度。
- 本机 npm registry 返回 403，标准 Vite 构建未能启动。交付 HTML 由模块源码离线打包，经过仓库单文件校验与三个窗口尺寸的 DOM 替身启动、购买和切档测试。
- 本机三组 Chrome 命令均遇到可执行文件缺失。冻结基线先通过 41 项非浏览器用例。真实浏览器画面、桌面掉帧与移动触控手感待核验。

下次试玩可从 W7 打开宝匣检验购买节奏，从 W25 带高星主印切换特效档，从 W29 打开详情观察计时，再进入 W30 检查危险圈与安全区的可读性。

## 代码位置

布局与快捷操作位于 `index.html`、`src/ui/styles/visual.css`、`src/ui/input/` 和 `src/ui/hud/`。天命与结算位于 `src/ui/modals/`。画面绘制与对象池位于 `src/ui/canvas/`、`src/ui/vfx/`，战斗系统通过表现端口通知命中与灵印触发。单文件交付于 `release/Border-Guard-v0.60.html`。
