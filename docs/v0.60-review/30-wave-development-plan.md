# 《边境守卫》v0.60 完整 30 波开发与试玩计划

2026-11-23 · PR #5 评审修订 · 供 Gemini 分阶段执行

## 交付与工作方式

交付一份能从开局打到 W30 结算、可离线打开的桌面试玩版。玩家在**一局里**经历普通升级、W10 改打法、装备联动、W20 第二次突破、后期精修和终局决战。开发按阶段提交，各阶段共用战斗循环、装备状态、存档和正式入口。开发中可用跳波、指定装备和固定种子复查问题，最终试玩从 W1 正常开局。阶段 1 可以开工，阶段 2 的普通材料优化和阶段 2–3 的两项联动细则按下文确认后再接通对应动作。窄屏触控做基本可用性检查，优先交付桌面完整局。

体验目标确定后，先做出可玩的实现，再以试玩发现的问题推动下一次修改。每阶段尽早运行浏览器冒烟测试，提交可接续的进度。整版接通后交给 Astres 自然试玩。同一个反馈先复现、再改动、最后用同一条件复测；核心规则的取舍由 Astres 确认。

## 已确认的规则

### 单局与成长

| 波次 | 玩家经历与已确认规则 |
| --- | --- |
| W1–W10 | 建立基础构筑；普通升级隔一级选一次神通卡，卡池分阶段开放。W10 战后进行首次大型突破，指定一个已学会的主力神通，再从其随机分支中三选一，改变该神通的打法。成长主线由普通升级和 W10、W20 两次大型突破组成，移除旧四次修为渡劫及其押注入口。 |
| W11–W15 | 用 W10 分支继续积累装备、词条和联动，让战斗能体现选了哪条分支。 |
| W16–W19 | 从 W16 开放 W20 突破方向预选，可以调整到 W20 开战前；W19 告知 W20 固定核心机制和本局随机辅助机制。此时只能使用已有战力。 |
| W20 | 开打时确认并锁定方向；Boss 按未完成第二次突破的战力标定。采用固定核心机制和本局随机辅助机制。失败直接结算本局。胜利获得专属凭证，当场生效已锁定方向的基础效果；战后再选一张强化进入 W21。普通材料为可选的强化重抽费用。 |
| W21 | 让玩家立刻感到第二次突破带来的变化。获得的突破方向、强化和已有装备组合继续跟随本局。 |
| W22–W24 | 围绕同一种主要威胁，用现有敌人的不同搭配逐波提升压力。玩家能沿用早一波学到的应对方式。数量可作为辅助参数，组合是主要加压手段。 |
| W25–W28 | 约相同的战斗压力，用不同敌群检验成型装备。每波从自己的若干候选敌群独立抽一套，相邻波可重复主要威胁。普通敌群开战后揭晓。W28 同时提供终局预兆。 |
| W29 | 比 W28 小幅升压，同时让敌群更紧凑、敌人稍耐打。W29 公布 W30 Boss 情报；普通战斗结束后进入独立的最终整备。 |
| W30 | 固定核心机制和每局随机辅助机制，击败最终 Boss 或失败后结算，一局在这里结束。 |

- 完整通关局目标 **25–35 分钟**，首轮以约 **30 分钟**为比较点。记录普通战斗、Boss 战、波间构筑、过渡各自耗时，再看整局节奏。固定关卡参数，同一敌群或 Boss 变体在不同构筑下的数值相同。
- W20 战后先给一组随机强化，玩家可以直接选一张。付费重抽会替换整组，新旧相邻两组没有同一张卡。材料够即可继续重抽，每次比上一次多花固定数量，界面显示下一次价格。正常优化装备且未刻意囤料的玩家，W20 战后通常付得起一次。测试材料为零、足够一次和足够多次三种情况；每组 K 张时，每个锁定方向在排除不适用和互斥内容后、排除上一组前，须有至少 2K+2 张有效候选；相容的共用卡可计入。验收覆盖多组实际可选结果及连续付费，避免两组固定来回切换；配置不足时修卡池，保留已有候选和材料余额。
- 构筑成长的关键节点应改变攻击形态、作用范围、目标选择、触发方式或操作联动；普通怪负责清群反馈，精英与 Boss 有清楚的预警和走位应对。灵印保留同系积累、分阶段升级和路线选择，关键进阶含金币取舍。华丽效果与可读预警同时验收。

### 装备、词条、商店与天命

- 装备品质和槽位数独立随机，1／2／3 槽概率为 50%／35%／15%。同件装备不会出现两个相同具体词条。词条有独立效果、双词条联动、三词条完整联动与必要的互斥。完整三词条联动替代原双联动，保留各原始词条的独立效果。极品联动可有明显质变，精英与 Boss 仍须应对。
- 商店承接常规装备优化，能低概率出现优秀词条。装备价格按当前购买阶段和同系重复购买次数递增；出售得金币、拆解得普通材料。回收以**装备自身的生成品质与阶段**为基准，与随机槽位数量独立。普通材料也由部分战斗奖励补给，用于常规装备优化和 W20 重抽。Boss 凭证为独立阶段奖励。
- 转移一次处理一个现有词条，扣除专属转印物资，保留原装备并把词条从原槽移除，目标可填空槽或覆盖已有槽。复制和同件重复词条均禁止。转印物资以天命赌局为主要获取渠道，也属于天命商城／赌局相关渠道；普通拆解和普通商店不提供稳定获取。
- 天命赌局自由押注，确认后扣押注并完成开奖；有空劫，失败押注归零。达规定门槛才有资格出珍贵内容。成功生成三件随机候选，玩家三选一；转印物资若在候选中，同样需要与另外两件取舍。灵印、构装、丹药、特殊强化四类各 25%，品质按概率，无稀有度保底。天命专属强化只来自天命赌局。普通商店与天命的奖励职责保持区分。
- W21–W30 保留装备掉落，逐步提升终局资源与装备优化机会的价值。后期把资源花在现有构筑精修，第三章没有第三次大型突破。W30 打完直接结算。

### 终局与长期成长

- W29 结束后以 **90 秒**作为首版最终整备倒计时，可主动提前进入 W30，倒计时归零自动进入。倒计时使用实际经过的时间，战斗倍速不改变整备秒数。打开商店、背包、装备详情、词条转移或天命赌局都继续计时。赌局沿用普通概率和成本。已赢但还没领取时，超时从当次已生成的三件候选中随机领一件。开奖、领取和转移各只提交一次；已确认操作先完整结清，未确认的购买／转移清空草稿。W29 波末战斗奖励（含升级和遗留宝箱）先单独结清，再开启倒计时；该过渡只处理波末奖励。超时所得装备或灵印作为未装备物品入背包，容量不足时暂存，已装备的主辅灵印和构装全部保留。提前结束的未领奖收尾见首版方案。
- W30 以正常成型的构筑为基准，目标 **3–5 分钟**。偏弱和偏强构筑用于检查两端，强构筑可以明显更快。固定参数，各档装备面对同一 Boss 血量。开场先正常交手，首次打到血线强制进入一次招牌招式，跨线多余伤害截断；从招式预警到冲击波结束，Boss 的生命锁在血线，结束当刻恢复扣血。该段合法命中仍可触发火标、减速、叠盾等命中效果；按实际扣血结算的吸血或伤害收益以 0 为基数。展示命中与锁血反馈，避免把两者混成同一判断。之后有中段周旋和末段招式组合，末段伤害正常结算，打空即可胜利。具体血线和用时按首测记录修正。统一从 W30 玩家可操作时开始计时，以胜利或失败结束。
- 局外配置开局前锁定：1 个主传承，最多 3 个辅助，总预算固定 4 点；里程碑和可积累的传承货币共同解锁新装备、词条、流派和挑战，主传承提高相关奖励权重，其他奖励仍可能出现。长期成长横向扩展，不通过永久叠伤害、生命等改变同一关卡的基础难度。
- 结算显示通关结果、本局表现、长期成长三部分。失败按真实进度提供基础成长，通关收益更高。展示实际选用的联动、死亡来源／已到波次、突破与 Boss 结果；至少有条件复核奖励未重复发放。

## 构筑联动的试玩验收

需要让玩家用**一套构筑，连续打多波，又能在另一局选不同组合**。实现时让词条直接改变实际战斗行为，选择界面写明已经激活什么、再加哪一条会怎么变。战斗保留必要提示，结算记录关键触发次数和效果来源，便于对照。

W10、装备和 W20 使用同一套战斗状态与触发逻辑。至少交付以下两条贯通的可玩链路。W10 改变建立状态的方式，装备决定状态怎样产生双／三词条联动，W20 锁定方向的基础效果与随后选择的强化继续改变同一套触发条件、影响目标或操作时机。数值可以随效果一起变化；每张 W20 强化至少有一项可观察的行为变化。一至二槽的常见装备也要能看出 W10 与 W20 的搭配，两套玩法的三词条分别作为进一步质变。

以下是**首版联动样例**。已确认的是上述跨阶段可感知的体验和联动替代关系。表内动作是用于实现和对照的样例，孤立目标与主动走位的具体三联动动作仍待确认。

| 样例 | 双词条联动 | 完整三词条联动 | 玩家实际怎么打 |
| --- | --- | --- | --- |
| 火系引爆 | 火系技能给敌人留下标记，命中被标记者时触发一次范围引爆 | 完整联动保留首次引爆，可有限向邻近带标记敌人传递；孤立目标额外动作待确认 | 主动把敌人拉在一起，再攻击合适目标；群怪成团时能看见爆炸传递。 |
| 冰系护体 | 命中已减速的敌人形成短时护盾 | 护盾受击可触发有限的冰环反制；走位不受击时的主动触发方式待确认 | 先制造减速和护盾，站位用于控场与抵御压力，战斗反馈和火系不同。 |

- 用同种子、同波次、同基础装备分别跑单词条、双联动、完整三联动；换组合后应能指认攻击扩散、控场或操作时机的变化。图鉴标签与增伤数值不足以通过此项。
- 交接记录写出两套玩法的“W10 如何施加状态 → 装备触发什么 → W20 改变什么”。用同一份常见装备做 W20 前后对照，确认 W10 分支持续参与、W20 零材料也有基础效果，选卡后操作或战斗结果可辨认。
- 每套打法至少覆盖 W21、两波 W22–W28 代表敌群及 W30 的单体和走位场景。群怪样本要有能演示先挂标再引爆的存活窗口，Boss 样本检查周边无可传递目标和主动避开攻击时仍有合理用途。阶段 3 先用同类遭遇验证，阶段 5 在真实 W30 复验。另以自然开局确认常见构筑可经正常掉落／购买／转移取得。
- 完整三联动触发一次就只能结算完整效果；转移、卸下或覆盖后立即重算。对递归爆炸、同一击重复触发和跨装备重复联动做测试。具体叠加边界见下表。

## 首版参数与待确认规则

已定规则按原意实现。下列数值和细则是**提请评审的首版方案**，归在可替换配置或小范围规则内。Astres 同意按本开发计划开始后可以用于整版试玩；验收后的取舍记录到各阶段交接。下节标注需单独确认的玩法细则仍待 Astres 选择。实现者可继续做无关部分，并在交接中说明哪些动作尚未接通。

| 项目 | 首版做法或待验证项 |
| --- | --- |
| W10 分支 | 保证可选的主力神通有足够分支可供三选一。先复用当前神通，首版分支池至少覆盖上面的两类构筑体验。W10 以打赢该波作为突破触发；任何额外消耗和凭证形式需要明确批准后才进入玩家规则。 |
| W20 强化价格与候选 | 起价、固定涨幅和候选数量独立配置，用实际可支配材料的分布校准。独立试玩的 4／6／8 与两张候选可作为测试用例。候选按锁定方向及共用条件筛选，遵守正文 2K+2 的有效候选下限。 |
| 双／三联动边界 | 提议单件同一冲突组只激活一个双联动，按配置优先级公开判定；同名联动全局生效一次，不同联动可并存。目标是先测两种可辨的打法，叠加范围留到对照结果后决定。 |
| 空槽、回收、防套利 | 试用出厂槽位填随机词条，提取后留空。建议购买、出售、拆解与转移的产出／消耗统一验算；优先用转印成本和回收上界防套利。若仍需增加“词条移除折价”，有意改动已选回收口径，提交具体漏洞和方案给 Astres 确认。 |
| 商店递增与词条权重 | 首测可用同系局内累计并设价格封顶；每阶段重置作为可对照的参数方案。品质与词条稀有度是否加权仍待验证，首测可以保持独立抽样。 |
| 天命领奖与转印 | 常规中奖三选一，W29 超时也只领一件。首测可把转印物资放在特殊强化类别内部，保留四类各 25% 的顶层权重。子池出现率，以及是否给完全不赌的玩家提供固定天命兑换，留在评审中确认。基础构筑用常规商店和掉落也要有通关机会。 |
| 天命数值与空奖 | 空劫概率、最低押注和稀有档门槛分别配置，首测记录真实押注与收益。对已满级或无法使用的候选提供同类别可用项作为首版建议，保留空劫与品质概率语义；奖励允许类型重复与否留作参数。 |
| W21–W29 后期精修 | 先串接现有装备购买、出售、拆解与天命转印。普通材料优化按下节拍板后接入；精修方案 C 的其余能力以库存、选择和试玩结果判断。 |
| W29 整备收尾 | 先试把 W30 情报放在 W29 开战前附近、整备页持续显示，避免长动画。玩家主动提前结束且还有赌赢候选时，首版建议先引导完成选择或明确接受随机领取；超时则按已确认的随机一件收尾。 |
| W30 阶段标定 | 50／110／80 秒与 20%／45%／35% 是首测参考，可独立调整，不作为三个固定计时段。先用标准构筑比较 3–5 分钟，偏弱和偏强各试，再调整固定敌人表；必要补给先用既有机制验证，不因随机辅助机制把某个正常打法完全封死。 |
| 局外解锁和奖池 | 先用小而可成局的内容池，验证新人与已解锁玩家都能凑出组合。固定容量活跃池、奖励公式、兑换价和存档迁移细节属首版评审。失败奖励按有效推进，避免反复速死在单位时间上成为最优路线。 |

## 进入对应阶段前需确认的规则

以下是评审提出的玩家玩法取舍。它们不拦阶段 1，也不拦阶段 2–3 中独立的装备、战斗状态和经济接口工作。

| 最晚确认时点 | 需要 Astres 选择的事项 | 评审推荐方案 |
| --- | --- | --- |
| 阶段 2 接通普通材料优化前 | 普通材料消费究竟改变装备的什么 | 提升装备基础属性的强化档位和已有词条的数值档位，保留原品质、来源阶段、槽位数及词条种类，词条转移仍用天命转印物资。先解决“旧装备好词条但基础属性落后”的原有问题，费用与收益在首测中标定。 |
| 阶段 2–3 接通火系完整联动前 | 孤立精英／Boss 周围无其他已标记目标时，火系三联动如何发挥 | 将剩余传递机会转成一次有上限的衰减聚焦引爆。 |
| 阶段 2–3 接通冰系完整联动前 | 走位避开伤害时，冰系三联动如何主动发挥 | 有盾时，通过主动冲刺或满盾刷新触发一次冰环。具体触发方式由 Astres 选定。 |

## 分阶段执行

整个版本使用同一开发分支。每一步先读上一阶段交接，保留正常入口能运行，完成自己的验收再提交。新会话从对应小节接手，记录从哪个提交开始和结束。

### 阶段 1 · 30 波骨架与 W10

- **输入**　设计基线、v0.52 战斗引擎、HUD 和数值表。
- **实现**　创建正式离线入口 `Border-Guard-v0.60.html` 和配置 `balance/v060-baseline.json`；接入 W1–W30、准备／战斗／奖励／结算。实现普通神通卡与 W10 指定神通、选择分支。迁移波次规则和成长入口，移除 v0.60 中的旧四次渡劫、W20 通关和无尽入口，替换旧指数缩放。神通卡池、主辅灵印星级上限和辅印槽改读可配置的波次／突破节点，首测以现有上限和 W10、W20 等适当解锁点衔接，不再从旧四次渡劫读状态。下架旧渡劫专属的护法丹、补天丹，清理修为丹等仍有效物品的旧渡劫说明。普通波间先沿用自由准备及可选自动开波，突破与奖励待选时暂缓开波；W29 使用独立计时。优先检查高伤害预警可读。
- **调试契约**　统一用 `window.BG60`。阶段 1 交付开发用接口 `BG60.loadTestPreset({ wave, tier, build, materials, gold, seed })`。其中 `tier` 接受 `weak`、`standard`、`strong`，`build` 至少接受 `fire` 和 `frost`。预设应初始化对应波次的战斗状态、等级技能、已完成突破、预算和固定种子。W10 战前与 W20 战前使用尚未完成本波突破的状态。阶段 2 补入真实联动装备，阶段 3 补入 W20 突破状态和后期掉落配置。尚未实现的内容在调试结果中明确标注。
- **过关**　从 W1 正常路径打到 W10，选分支后打法或动作有可观察变化；状态可以继续进 W11。检查灵印及神通池随已配置节点开放，旧渡劫专属丹药不进新奖池。用同一调试接口进入 W20、W29、W30，验证等级、已完成的 v0.60 突破和资源随预设初始化，走通已有的终止与失败路径。未完成的 Boss 或奖励用明确标记的临时数据，每阶段逐步替换。
- **交给下一阶段**　真实战斗入口、分支状态、波表、调试命令与槽位／星级迁移验证记录。

### 阶段 2 · 装备词条、联动和普通经济

- **依赖**　阶段 1 的升级、战斗效果与波次状态。
- **实现**　独立的品质／槽位生成、来源阶段、佩戴和合规替换、双／三词条联动、常规商店价格、出售／拆解和材料接口。接通普通材料优化前取得上节确认；其他装备与经济路径可以先做。给玩家显示目前的联动和差哪一条，落地至少两套可重复的不同打法。沿用同系灵印积累，提供可比较的分阶段进阶。
- **过关**　固定种子可举行单／双／三词条对照。覆盖跨波、换装、回收与构筑测试预设的重载，装备实例、槽位与联动一致；正常重开清空上一局的装备与联动。这里的预设重载属于调试接口。覆盖旧自动合星对新词条、跨波回收升值及买卖循环获利的影响。
- **交给下一阶段**　装备与效果定义、构筑预设、两套有图像或录屏证据的联动对照、经济记录与材料接口。

### 阶段 3 · W16–W28 贯通

- **依赖**　阶段 2 的装备、材料与联动。
- **实现**　接通 W16–W19 预选与 W19 情报、W20 Boss 成功／失败、凭证保障、付费整组重抽、W21 强势体验。配置 W22–W24 共同威胁递进和 W25–W28 独立敌群抽取，保留 W28 终局预兆。将 W20 基础方向效果与强化落到 W10、装备共用的战斗状态和触发逻辑，保持二者各自的生效时点与跨波状态。
- **过关**　同一份构筑从 W16 打到 W28，至少记录 W21 与两波后续战斗的联动作用。胜利、失败、零材料、不重抽、重抽一次、连续重抽、相邻组不重样、各方向在适用条件下的候选池下限及多种连抽结果均可复查；随机敌群无战前剧透，并测多种种子下的压力与连抽波动。
- **交给下一阶段**　W28 结束时的真实装备、余额和掉落状态、Boss 情报／奖励交互及已知难点。

### 阶段 4 · 天命赌局、转印和终局精修

- **依赖**　阶段 2 的装备与普通经济、阶段 3 的后半局循环。
- **实现**　接入押注门槛、空劫、概率池、成功候选与领取，提供转印渠道；用已有物品、词条和材料连接 W21–W29 精修。转移确认一次性校验来源、目标、当前槽位和余额，统一完成扣费、移除与填入／覆盖。
- **过关**　低押注进不了珍贵池，失败只扣合法押注，赢后只发一次；取消预览不变更资源。空槽填入、覆盖、重复词条拒绝、互斥和联动更新正确。分别走常规经营和赌局两条路，检查 W28–W29 是否还有有意义的材料用法。
- **交给下一阶段**　单次结账入口、已开奖未领取状态、转印及阶段经济回归用例。

### 阶段 5 · W29 最终整备与 W30

- **依赖**　阶段 3 的 Boss 情报、阶段 4 的交易和未领奖结果。
- **实现**　W29 两项同向小幅升压、波末奖励结清、战后整备入口、实时 90 秒、提前开战、自动进战和未领奖收尾。超时自动发放走领取路径，禁止复用会自动卖掉或替换在用灵印的旧购买路径。W30 按已定招牌招式及各段规则落地，独立处理命中与 HP 扣减；测试正常／偏弱／偏强构筑，生成固定 Boss 数值与时间记录。
- **过关**　倒计时归零时分别验证浏览详情、购物确认、赌赢未领、转移预览和快速重复点击。另测遗留宝箱／升级结清后才启动计时，以及超时随机抽中异系灵印、且主辅槽及背包已满的情况。进入 W30 时账户、装备和奖励一致，已扣款动作有结算，主辅灵印和装备原样保留。极强构筑也要经历一次招牌招式；验证锁血期合法命中能挂状态、叠盾，实际扣血与按伤害吸血为零，招式结束恢复扣血。末段打空即结束。标准参考构筑的实测目标为 3–5 分钟。
- **交给下一阶段**　完整终局、Boss 阶段时间表、两类结算入口、所有边界操作结果。

### 阶段 6 · 局外传承、存档与整版验收

- **依赖**　前面阶段的局内状态、结算和可追溯奖励。
- **实现**　开局前配置、传承解锁与存档、三维结算、失败和通关奖励，再开一局使用新解锁。用完整 30 波局调整掉落、节奏、先前的临时内容与反馈；交一份从 W1 开始的最终试玩文件。
- **过关**　自然通过 W1–W30 并结算后可重开；覆盖 W20 与 W30 失败、W30 通关、刷新重开防重复领、固定 4 点和最多三个辅助。记录至少正常通关路线、偏弱及强势构筑的差异、完整局 25–35 分钟目标、最低血量、关键受击来源、联动贡献、普通材料和终局资源收支。验证至少一条无需押注也可完成的常规路线。
- **交付**　当前版本入口和 commit、实测记录、已知问题与下轮待确认规则。以连续自然试玩复查每一波之间的衔接。

## 评审范围

请沿着正常玩家流程核对四件事：

1. 已确认规则是否有误录或遗漏，尤其是 W20 基础突破、W29 赌赢超时、W30 招牌招式。
2. 仅持有普通装备的玩家，能否在一局里获得和使用至少一种有明显行为变化的组合，效果能否延续到后续。
3. 各阶段交给下一阶段的运行入口、数据或状态是否足够，是否存在失败／归零后无法继续的路径。
4. 哪些首版假设会改变用户已确认规则，是否有足够小的替代做法。

用“具体玩家场景 → 可复现的冲突 → 建议改法 → 影响阶段”给意见。评审集中在会让整局跑不通或背离已确认体验的事项。组合数值、出怪小调和视觉表现随可玩版本迭代。
