# v0.19 全画幅地图与触摸手势

用户最新截图为视觉依据，覆盖先前侧栏布局：地图铺满视口，标题/资源为顶部HUD，战报左下、目标/结算右下，无固定右侧列。参考图的旧资源/结转文案不复制，保留真实库存与分夜账目。保留v0.18，新建v0.19离线单HTML。

先统一稳定骨架，消除旧媒体查询叠加与地图被flex压缩，再实现手势。桌面为角落悬浮卡；触摸设备（含手机横屏）详情为底部抽屉。顶部突出时间、资源、行动；开发备注、试玩参数集中到说明，不常驻玩家面板。

手势：短按可通行地块只移动，350ms长按仅查看/高亮该格并给明确建造按钮；超过10px变拖图，取消长按与移动，关闭抽屉。pointercancel、多指、失焦、新局清理定时器。阻止合成click导致重复操作。战后地图保持只读。鼠标点击与WASD保留原业务。

抽屉：44px触摸按钮、遮罩点击或下滑手柄关闭，允许内容独立滚动，地图拖动时关闭。手机横屏也使用触摸UI，不以720px宽度单独判断设备。竖屏为回退，横屏优先。

业务复用：开发/占领/建造/派驻函数不复制。只增加地点面板中的明确动作入口，避免短按在建造模式直接扣资源。不改成本/波次。本轮不混入其他数值平衡。

验证：1440×900、1920×1080桌面；844×390、932×430触屏横屏；390×844竖屏。检查地图容器覆盖视口、卡片有界、抽屉可滚动；真实短按/长按/拖动/取消、遮罩与滑动关闭、PC不回归。已有玩法20项与适用的胜利记录测试仍通过；旧“胜利隐藏顶部”断言依据本次参考设计更新。
