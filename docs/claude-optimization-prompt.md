1. **玩法**：优先修复阻断流程、资源/产出错误、寻路卡死和交互失效，再优化探索选址、居民分工、资源开发、建造布防、夜间战斗和三选一成长之间的决策。评估行动点、成本、产量、敌人强度与节奏，避免机械重复或唯一最优解。调整要给出理由与同种子前后实测，不要无依据叠加系统。
2. **美术**：朝用户参考图的卡通中世纪策略游戏风格统一地图、城堡、整圈城墙、生产建筑、居民、敌人、图标、特效和 HUD。提高层次、轮廓、色彩和状态辨识；农场、伐木场、采石场、矿场必须各有外观，禁止用箭塔代替。资源开发后旧自然图标/覆盖不应与建筑重叠；工人应在对应建筑的作业区可见。保持资源离线可用，外部素材需有可用授权，不要把概念图包装成已实现画面。
3. **布局**：保留顶部资源状态、左侧可折叠图例/小地图、右侧详情、底部建造命令、中央三选一卡牌的清晰结构。地图是视觉主体，减少常驻遮挡，真实可点击区与视觉一致。按面板的实际位置计算镜头安全区，避免详情与底栏重叠、手机汉字竖排、按钮裁切、透明容器拦截地图。适配桌面、竖长窗口、横屏触控和手机；不要只优化一个截图尺寸。
4. **全面检查**：走完选址→建城→开发→派工/移动/召回/改派→入夜→破墙/修墙→天亮→胜利/失败/重开，检查暂停、弹窗冻结、缩放、拖动、地图点击、触控和控制台错误。重点复查夜间清场无法结束、敌人卡死、收入重复结算、拆除后仍产出、卡牌失效等是否仍能复现。

保留已确认的规则：城墙整圈共享耐久，归零整圈倒塌；破墙后主城应很快失守。当前试玩值为圈墙 600、主城 50，可以基于实际战斗证据调平衡，但不能改回逐段独立血条。友方居民可以穿过资源地形，到岗后仍能移动/召回/改派，不能传送到主城两侧。顶栏真实资源为金币、材料、粮食、稀缺资源，不要仅在 UI 虚构独立木材/石料余额。

验证至少覆盖 1440×900、1920×1080、1108×1195、886×956、1108×720、932×430、390×844。使用真实鼠标/触控输入检查所有关键按钮，A/B 两个选址按钮都要完整显示且可点；验证三张卡牌都可选，面板展开/收起后镜头与地图仍可操作。浏览器自动化中可以设置可控测试状态，但必须标明夹具，另做完整自然流程试玩；不能用直接调用内部函数代替用户交互的验收证据。
