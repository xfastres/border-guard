# Hex World v0.2 · 地图视觉迭代记录

日期：2026-11-18
基线：`prototypes/hex-world-v0.1.html`
交付：`prototypes/hex-world-v0.2.html`

## 本轮目的

根据实际试玩截图，v0.1 的地图表现被反馈为「太难看」。问题不只是缺少装饰，而是地图整体呈现为低对比度暗色六边形底板、零散地形小图标和中心区域孤立的可见地块，缺少自然地貌的连续性和空间层次。

本轮只处理地图视觉与地形生成观感，不改移动、战争迷雾状态规则和昼夜行为。

## v0.2 调整

- 地块增加渐变、侧边阴影、柔和高光与更轻的边线，减少平面棋盘感。
- 森林改为多层树冠组合；丘陵增加坡面和阴影；山地使用多峰与雪线；水域增加水纹。
- 陆地相邻水域增加浅色海岸边缘。
- 未探索格改为蓝灰雾面和柔和雾光，降低黑色网格的压迫感。
- 画布背景改为海蓝水面纹理，地图外部不再露出单色草绿底。
- 城堡和领主重新绘制，提高地图上的视觉辨识度。
- 地形生成从独立随机改为连续噪声与大陆轮廓组合，形成连续海岸和相邻地貌群落。

## 保留的玩法行为

- 六边形坐标和点击移动。
- 领主逐格实时移动与地形耗时差异。
- 未探索 / 已探索 / 当前可见三种迷雾状态。
- 城堡与领主视野。
- 昼夜切换时领主位置连续保留，夜晚仍可移动。
- 资源点和遗迹仅在发现后显示。

## 验证范围

- 内嵌 JavaScript 语法检查通过。
- 连续噪声地形分布脚本检查通过。
- 六边形地形、海岸绘制、森林/丘陵/山地绘制、未探索雾面和昼夜移动相关代码存在。
- 无外部图片、字体 CDN 或运行时依赖。

## 未验证与下一步

- 本轮没有完成真实浏览器截图的视觉验收，也没有真人试玩验收；代码检查不能证明最终画面符合预期。
- 需要用户在本机 Chrome 打开 v0.2，判断整体色彩、地块比例、地图占屏、地形丰富度和战争迷雾质感。
- 如果整体视觉仍不符合预期，先调整地图视觉与构图，不继续叠加战斗、经济等系统。
- v0.1 保留作视觉对照，不覆盖。
