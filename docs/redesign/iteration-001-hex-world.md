# 迭代 001：六边形地图与昼夜连续移动

> 状态：原型范围已记录，具体手感待试玩。
> 目标文件：`prototypes/hex-world-v0.1.html`

## 本轮只验证一个问题

玩家是否愿意在一张未知的六边形世界地图上，自己规划路径、逐格探索，并且接受领主在黄昏和夜晚仍留在原地、继续使用同一套移动能力？

## 玩家进入原型后应该能做什么

1. 看见城堡附近有限范围的初始视野。
2. 看见未探索区域被战争迷雾遮住，不能提前识别地形与资源。
3. 点击已知地块或探索边缘的未知地块，让领主沿六边形路径实时行走。
4. 行走过程中逐步揭开新地块；已经探索过的地块保留地图记忆。
5. 发现资源或遗迹时，收到明确提示；本轮只展示发现，不开放建设和采集。
6. 昼夜时钟持续推进；黄昏/夜晚不会传送领主，也不会锁住移动。
7. 玩家能平移和缩放地图，能看懂基本操作提示。

## 验收标准

- 未探索地块不显示地形、资源、遗迹或敌人信息。
- 已探索但不在当前视野的地块保留地形记忆，并降低亮度。
- 城堡和领主分别提供有限视野。
- 领主跨地块移动有真实过程，不瞬移。
- 森林、丘陵等地形可以使用不同的移动耗时；暂不加入每日移动点数。
- 昼夜切换只改变世界阶段，不重置领主坐标，不重置移动能力。
- 点击明显可达的地块可以移动；点击远离已知区域的迷雾不能隔空寻路。
- 基本操作提示在首次进入时可见。
- HTML 可以离线独立打开，不依赖 CDN 或外部资源。

## 本轮明确不验收

本原型没有完整敌人 AI、夜间战斗、城墙、资源经济、居民、营地、建筑、卡牌或 BOSS。因此它不能用来判断完整游戏是否好玩，只用来判断地图探索与昼夜连续移动的基础体验是否成立。

## 试玩反馈重点

请优先观察并反馈：
- 地图是否有「外面还有未知世界」的感觉？
- 逐格移动速度是否自然，是否感觉拖沓？
- 视野揭开范围是太大还是太小？
- 未探索区域是否真的让你想去看看？
- 黄昏时领主仍在外面，是否产生了合理的风险感，还是只觉得被计时器催促？
- 不看开发说明，第一次进入的人能否理解如何移动？

不要因为原型可以运行或自动化检查通过，就判定体验已经合格。
