# v0.52 数值系统拆分与推演

> 基础分支：`feat/c-hybrid-hud`（C-Hybrid 双侧 UI）。数值实验室建立在该 UI 改造之上，保留战况与构筑面板；合并顺序为 UI → 数值。请勿直接将此分支的 PR 目标改回 `main`，以免重复展示 UI 改动。

## 为什么拆

原游戏的波次、经验、敌人、商店、奖励分散写在单体 HTML 的不同函数中，且原 `tests/v052-sim-curve.cjs` 自己复制过一份公式，**漏掉后期血量增长因子**。在完整数值推演前必须解决来源漂移。

## 单一配置源

- **改数值只改** `balance/v052-baseline.json`
- `node scripts/sync-balance.cjs` 将完整 JSON 快照嵌入可离线打开的 `Border-Guard-v0.52.html` 与 `balance/v052-lab.html`
- `node scripts/sync-balance.cjs --check` 检查两个快照是否与 JSON 相同
- `node balance/v052-sim.cjs` 看 20 波理论生命/经验/金币和目标清怪 DPS
- `node balance/v052-sim.cjs --csv` 或 `--json` 方便导出、筛选或绘制
- 双击 `balance/v052-lab.html` 即可离线调整核心数值、对比曲线、导出候选 JSON；需要同目录 `v052-engine.js`

## 当前已集中控制（仍保持 v0.52 原版数值）

| 分类 | 参数 |

| 敌人 | 11 类怪的 HP、移速、攻击、掉落经验与金币 |
| 怪潮 | 基础数量与上限、6段波次概率/精英包调整、三段出怪节奏、Boss 出场时点 |

本版未直接重平衡，不会修改原版基础玩法数值；配置生成的嵌入快照保证单 HTML 仍能离线试玩。

## 特别强调：推演的五个假设

1. 所有敌人最终被击杀，且经验与金币完整获得。
2. 低价值怪掉金币时按 52% 的期望值计算；无饰品、改命、额外金币、妖碑奖励。
3. EHP 指出生血量之和，并非真实有效生存（排除护盾、回复、召怪、过量伤害）。
4. DPS 要求用 **敌人总血量 / 假设清怪用时**，它不是游戏实际 DPS，实际应从每波 `telemetry` 取样验证。
5. 升级等级采用波末稳妥渡劫（100% 成功）的简化模型；真实游戏可以在波中渡劫，强行渡劫也有失败惩罚。

## 发现的问题与下一阶段建议

- 后期会受到 `1.26^(波次-1)` 和 `1.05^(波次-11)` 的双重指数增长；对 W12–20 的 EHP 需要重点压测。
- 旧推演没有考虑后段额外血量指数；原本的经验估算也未正确处理渡劫卡级。
- 当前仅集中 **最重要的全局参数**。装备与词条中的局部数值仍分散在 `ARTIFACTS`、`GEARS`、`PERKS`、`SUB_SEAL_RESONANCE` 等数据表；它们需要下一批迁移，不能宣称全部数字已经拆完。
- 请使用真实战斗体检记录（每波存活率、耗时、伤害、有效 DPS、回血、装备、冲刺次数）建立目标区间，再提出候选倍率；不要先盲目改伤害。
- 确保使用同种子、同构筑对照。**UI 交互优先级 > 单纯补数值**。
