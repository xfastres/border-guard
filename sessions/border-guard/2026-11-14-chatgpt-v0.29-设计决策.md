# 《边境守卫》v0.29 设计决策记录

- 日期：2026-11-14
- 状态：版本范围已确认，等待 Cursor 实施和试玩。
- 来源：本轮 v0.29 评审、决策汇总与补充确认。以下以讨论纪要为主，关键答复摘录原话。
- 执行入口：[Border-Guard-v0.29-Cursor-Plan.md](../../Border-Guard-v0.29-Cursor-Plan.md)

## 为什么做这一版

第 3 夜之前，玩家应能看见来袭方向、防守缺口和城堡状态，再决定修城、补塔或留材料。天亮后能对照自己做的准备和实际结果。讨论时比较过先做生存闭环的小版本和同版交付 P1–P5 两条路，最后确认同版交付，并按四阶段留验收记录。这样可以在阶段 1 单独验证生存改动，再依次接入建造、经营和战斗改动。

## 确认顺序

1. 评审首先指出三处需要补齐的规则：无城首夜的失败条件、风险预告的依据、界面示意数字与正式数值的区别。用户澄清首夜建城可选：「不是必须，如果没有建城，领主死亡就直接游戏结束」。
2. 用户要求先一次看全待讨论问题，再整理和确认。随后逐项提交《Border Guard v0.29 决策汇总》，确定四阶段交付、同阶段经济对照和各玩法规则。
3. 第一版 Cursor 计划把无依据的掉血提问改成方向和缺口，将首轮经济参数与阶段 3 的建造功能分开，并把倍速列为唯一需拍板的事项。用户随后确认这一版加倍速并要求在 GitHub 留档。

## 已确认的规则和取舍

| 议题 | 已确认 | 讨论中的取舍 |
| --- | --- | --- |
| 范围与顺序 | v0.29 交付 P1–P5，按生存、建造与卡牌、产出与驻派、战斗四阶段验收。 | 同版体验完整。阶段验收和经济对照用于追踪第 3 夜变化的原因。 |
| 首夜建城与失败 | 首夜可不建城。无城时领主死亡，本局立即结束。建城后领主倒下只退场，城堡耐久归零才失败。 | 强制建城会移除「再探索一会，冒险守首夜」的选择。无城入夜前明示风险。 |
| 退场与天亮 | 退场后停用领主攻击、横斩、药剂和号令齐射。紧急加固、全局指挥民兵、暂停、查看和倍速继续可用。天亮城堡回 8。存活领主回最大生命 10%，退场领主以 50% 最大生命复活。 | 领主倒下有代价，玩家仍有机会靠布防和救城守到天亮。 |
| 修复与休整 | 白天城堡修复花 1 行动＋3 材料、回 25%。夜间城堡加固花 6 材料、回 15%，取消夜间修墙。白天领主在城堡正交相邻格花 1 行动休整、回 30%。夜间药剂花 4 金币、回 25%。四种命令分别限一次，按各自昼夜重置。 | 分开城堡和领主的消耗与恢复入口。夜里集中保留救城操作，墙压力留待阶段 4 试玩检查。 |
| 次夜预告 | 显示来袭方向、缺塔入口、当前耐久和白天修复收益。 | 先提供玩家能从地图核对的线索。掉血预测需要独立验证，v0.29 排除。 |
| 通行与建筑外观 | 己方可穿过城堡、营地、资源点和箭塔，城墙仍拦己方。敌方按既有格子规则处理。城墙不能封死城堡四邻可站格。做墙连接图与塔基、建筑地基，站上塔仍需单独指派。 | 通行和绘制分别验收。连接外观仅用于识别，耐久、受击与阻挡继续按各格结算。 |
| 建造与每日卡 | 3×2 建造网格可留空，重型塔灰显并引导改装。首次建城后出第一组卡，以后每天早晨三选一，可跳过，弹出时暂停白天计时，效果至当晚结算。复用旧入口，隐藏旧经验强化。卡牌式布局只用于选卡。 | 保持一套可见的三选一入口。重型塔继续走原有改装路径。 |
| 资源与驻派 | 主城资源点提供建造位置与类型限制，对应产出建筑建好后天亮自动到账。主城产出建筑可驻一人加 25%，外围营地沿用旧规则。驻派防御设施的居民夜间成为临时民兵，天亮恢复居民身份。 | 玩家看得出「森林 → 林场 → 天亮拿到材料」，基础产出无需采集。先验证协防，维修分支留作后续。 |
| 新经济与对照 | 首个试玩版启用主城普通产出 +4、基础塔 8 材料＋3 金币。阶段 1 另跑同阶段旧经济（+3、塔 10 材料＋4 金币）和原版 v0.28。阶段 3 才接造产出建筑。 | 用 v0.28 对比阶段 1 旧经济观察生存改动，再对比阶段 1 两个经济档观察经济增益。三组均使用常速。 |
| 战斗 | 领主优先打正在攻击城堡的敌人，其次打离城堡最近的敌人。塔具小范围溅射，民兵攻击附短暂减速。原「冲锋斩」按原地前方一格范围斩击实施，界面建议称「横斩」。 | 优先级可按实际威胁验收。取消位移可以沿用现有遮挡和命中规则。 |
| 试玩判据 | 记录玩家是否能解释修复、补防或留料的选择。只有城堡受损且付得起才计入修复机会。另记录第 3 夜失守、夜间加固、卡牌跳过和领主退场等数据。 | 第 3 夜是否守住是辅助数据。小样本保留分母和选择理由，比例只作参考。 |

阶段 3 的产出建筑试用成本为 **4 材料＋1 行动**。完整参数、阶段验收及保留范围见执行计划。

## 倍速是怎么定下来的

1. 决策汇总要求领主退场后仍可「暂停／加速／查看」。核对 v0.28 后发现已有暂停和查看，当前试玩界面没有可操作的倍速入口，因此单独列为待确认。
2. 用户确认「这一版可以加上倍速」，随后要求更新执行计划并将计划和交流留档到 GitHub。倍速因此纳入阶段 1 和退场验收。
3. **本轮给 Cursor 的试玩默认**是仅夜战提供 `1×`／`2×`，每夜从 `1×` 开始，退场后保持并允许切换。暂停后恢复沿用当夜档位，白天和结算使用常速。倍率和开放时段可依据试玩调整。

## 写入 Cursor 计划时统一的细节

- 城堡初始耐久 160、领主初始生命 100。修复、加固、休整和药剂对应回 40、24、30、25。若提高上限，按当时上限计算。
- 试玩原题「预计掉多少耐久」改成「下一夜从哪里来，哪一处缺防，你准备怎么做」。
- v0.28 的夜间 3 材料用于修墙，城堡急修原价为 5 金币。v0.29 的夜间 6 材料用于城堡加固。药剂按 4 金币。
- 卡面示例、防御设施每座一人、预告检查城堡附近 3 格和百分比回复四舍五入，属于执行计划的试玩默认值。
