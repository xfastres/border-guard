## 1. v0.53：局外养成最小完整闭环

### 1.1 持久化架构（第一个存档系统）
- `localStorage` 存储键 `border_guard_meta_v1`，含版本字段 `schemaVersion` 以支持未来平滑迁移：
  ```json
  {
    "schemaVersion": 1,
    "spiritStones": 0,
    "daoYun": 0,
    "unlockedNodes": [],
    "milestones": [],
    "banishedKeys": [],
    "bestWave": 0,
    "bestTrial": { "wave": 0, "time": 0, "kills": 0 }
  }
  ```

### 1.2 双货币与深度结算（保赌感、抗挫败）
- **灵石（软货币）**：每局结束按深度结算，用于修炼树常规节点与便利节点。
  - 起点公式：`10 + 到达波数 × 3 + 击杀Boss数 × 15 + 天道渡劫次数 × 20`（第 3 波暴毙 ≈ 19；20 波通关含 2 天道 ≈ 170，差一个量级）。
- **道韵（稀货币）**：来自一次性里程碑与高光表现，用于解锁新法宝/新配方/新构装图鉴/稀有节点。
  - 来源：首斩各 Boss（`+5`）、首次到达各大境界、首次天道渡劫、每次天道额外 `+2`、裸装试炼新纪录档位。

### 1.3 首次到达里程碑（咬合 v0.52 境界脊柱）
- **首次筑基** → 解锁「开局筑道」面板（宗派声明 + 起始神通自选）+ 灵石。
- **首次金丹** → 解锁「商店图鉴层」（新构装进池 + 掉落池封印槽位 1 个）+ 道韵。
- **首次元婴** → 解锁「先天气运 6 选 3」与高阶改命池扩展 + 道韵。
- **首次化神 / 首通 20 波** → 解锁隐藏组合技配方 + 裸装试炼高阶种子 + 大额道韵。

### 1.4 修炼树（选项解锁为主 + 硬封顶便利）
严格禁止无上限百分比攻击/血量节点，守住 `1.26^w` 曲线与渡劫心跳：
- **起始层（选项）**：解锁宗派流派（剑风宗 / 雷火宗 / 寒刃宗 / 体修宗）、先天气运候选池扩容（3选1 → 6选2 → 6选3）。
- **图鉴/池层（选项）**：见闻录式解锁新构装与新法宝进局内掉落池；解锁「封印提纯」名额（最多封印 2–3 件非本流派构装或法宝牌，`rollShop` 与宝箱自动过滤，实现掉落池版的“精简 = 强度”）。
- **便利层（硬封顶）**：起始金币 `+10`（封顶 1 级）、每局免费刷新 `+1`（封顶 2 级）、开局护盾 `+25`（封顶 1 级）、丹药位概率 `+5%`（封顶 1 级）。

### 1.5 统一「开局筑道」单面板（归总宗派 + 气运 + 封印）
避免开局弹窗多层套娃，把鬼谷「先天气运」、暖雪「宗派声明」、掉落「封印提纯」合并为**开局一步完成的单页筑道面板**：
1. 选 1 个宗派（决定初始神通 + 本家掉落/改命微倾斜）；
2. 从随机 6 条 build 定义型「先天气运」里挑 2–3 条（非纯数值，例如「御剑开局：自带 1 把疾风飞剑」「丹道世家：商店丹药半价」「天劫之体：道心初始 +1」）；
3. 可选勾选 1–3 个封印项提纯奖池 → 点击「入秘境开刷」直接开局！

## 2. v0.54：构装深度（暖雪 4 槽）× 裸装试炼 × 红魂挑战

### 2.1 暖雪式「主角 4 功能槽」（同件构装放不同槽激活不同面向）
v0.52 已把领主构装统一为 **4 槽**，v0.54 只需为这 4 槽赋予职能身份，**零新增槽位数量、零构装膨胀，10 件构装 × 4 槽 = 40 种规则变化**：
- **核心槽**：定义流派输出核心（改变攻击形态/触发大招）
- **力量槽**：攻防转换与重击倍率（参照玄武之魂：护盾/血量转伤）
- **敏捷槽**：移速/冲刺/闪避触发机制（冲刺留冰径、移动叠暴击）
- **功效槽**：极端规则弯折与玻璃大炮取舍（参照憎恨之心：`+100%` 伤但受击 `+50%` 痛，与渡劫赌感同构）
- **双轴正交**：v0.51 叠星保留为「面向内强度轴」，4 功能槽为「效果面向轴」；**传说构装**额外附带 1 条唯一固定特效。

### 2.2 裸装试炼 / 论道（技术验证与养成分离）
- 剥离全部局外修炼树/气运/封印，使用**固定种子 + 标准初始配置**，纯比大地图走位、法宝合星、渡劫押注决策。
- 本地最佳榜记录到达波数/用时/总伤；道韵奖励按 **首次突破波数档位（10 / 15 / 20 波）** 发放防刷。

### 2.3 红魂波次风险挑战（把赌感从渡劫扩到波次层）
- 备战期提供可选「心魔/红魂契约」开关（如本波怪血 `+30%` 或领主持续掉血换高吸血），换取本波掉落品质提升、金币 `+40%` 或下一次渡劫天道概率 `+5%`。

## 3. 远期 Backlog（明确不急于排期）
- **渡劫 QTE**：雷劫落下时 3 次时机按键（Space）微调开奖权重。
- **组合技·引擎层**：翻转关键词（如「嗜血：受击回修为」）与跨波叠层复利引擎（如「剑意」击杀叠层增飞刃伤）。
- **构装随机词缀**：史诗/传说掉落额外 roll 1 条随机词缀。
- **难度分层（Ascension）**：通关 20 波解锁更高天劫难度（细雪→白灰→狂雪式阶梯）。
- **UGC 组合分享与联网排行**：需独立后端与平衡审核，远期留档。
