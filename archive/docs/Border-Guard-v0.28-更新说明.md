# 《边境守卫》v0.28 试玩问题记录

基线为 v0.27 的 `32bcfea`。双击 `Border-Guard-v0.28.html` 可离线试玩。以下四项来自玩家反馈，列为本轮优先修复。

| 编号 | 玩家反馈 | 本轮改动与验证 |
| --- | --- | --- |
| BG-028-01 | 敌人遇到领主仍继续前进 | 敌军进入近战距离后停步交战，在攻击间隔内也会停留。领主拉开距离或倒下，敌军继续进攻。专项用例验证了停步、伤害与恢复行军。 |
| BG-028-02 | 居民和民兵看不出在攻击，也无法操控 | 点单位，选择「移动到指定地块」，再点驻地内可达空地。民兵和受训守卫从自己的站位自动攻击，普通居民可移动。驻营居民的移动范围限于自家营地，夜间撤离仍走营救流程。专项用例覆盖了点击下令、实际走位和弹体伤害。 |
| BG-028-03 | 领主穿不过营地与箭塔 | 领主的键盘移动和点击寻路都可经过这两类己方建筑格。城墙、城堡及地形仍阻挡领主。敌军的建筑碰撞和拆墙规则沿用 v0.27。专项用例覆盖了两种移动方式。 |
| BG-028-04 | 新占领地没有建墙入口 | 桌面和手机占领空地后，地点详情都可直接点「建造城墙」。占领费用和建墙费用分别结算。资源格显示开发选项，并引导到相邻空地建墙。专项用例验证了占地、点击建墙和扣费。 |

## 可复跑回归

```sh
node --test tests/v028-priority.cjs
BORDER_HTML=Border-Guard-v0.28.html node --test tests/v027-balance.cjs
```

6 项新专项与 10 项 v0.27 专项回归通过。6 组固定种子战役模拟均进入胜负结算。真实浏览器手感、手机真机交互，以及领主拦截和守卫站位对难度的影响仍待试玩验证。
