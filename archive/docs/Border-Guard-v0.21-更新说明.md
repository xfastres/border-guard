# v0.21：战役目标层（让每夜有奔头、每局有追求）

打开同目录 `Border-Guard-v0.21.html` 即可离线试玩。`Border-Guard-v0.20.html` 未改，SHA256 仍是 `3D947C8AA6C9DA88D9B4E3A4D02FCCD82D4B930B287B4ABE16B932809DA9C02D`。

## 这轮解决什么

v0.17–v0.20 四轮把「看得懂、点得准、账算对、镜头跟得上」做扎实了，但玩家仍只是在执行一份 5 夜清单：每夜结构相同（换个门、敌人加血）、成长卡片最多 2–3 次、地图上 6 处隐藏内容没有引导、赢了之后除「再来一局」没有理由再开。

v0.21 只补一层：**目标与节奏**。不改战斗公式、波次、经济与任何平衡数值。

## 玩家会感受到的变化

1. **常驻战役浮层**（PC 左上 / 手机顶部资源条下方）：「今夜 / 军令 / 秘点」三行，PC 与手机默认都能看见，不再依赖收起的抽屉。HUD 本体不吃指针事件，地图仍能从这块起手拖动。
2. **每夜军令**：每天给 2 条可选挑战，接一条或跳过。可跳过、失败无惩罚、不影响通关。达成给 1 战功 + 3 主城经验 + 下夜多一次号令；未达成只写一句中性战报。6 种：不落一砖 / 领主亲征 / 守住阵线 / 边境踏勘 / 战前备战 / 开垦。
3. **今夜预告**：把已有的入口方向、敌军规模、重甲与双线规则提前说出来，白天准备有针对性。**只讲规则，不改波次**。
4. **探索图鉴**：6 处秘点（富金矿、铁矿、守望遗迹、幽谷遗迹、封印石台、古哨遗址）走近点亮即记入，只给方向提示不剧透坐标；集齐额外 +3 战功。
5. **夜间号令**：每夜 1 次主动齐射，对全场敌人造成一次伤害（试玩值 8 + 塔×4 + 民兵×3），不使用也不会输。击杀仍走既有入账通道，账本不受影响。
6. **跨局战绩**：结算卡显示本局战功 / 军令达成 / 秘点进度、个人最佳，以及一条基于本局真实状态生成的「下局可以试试」。记录只写本机浏览器 localStorage，不上传、不含任何个人信息；写入失败静默降级。败局同样给出下局建议与死因摘要。

## 三处刻意的设计约束

- **军令奖励不发资源**：只给战功、经验与号令额度。避免改动库存与账本，也避免「为了奖励被迫按某玩法玩」。
- **军令抽取不消耗 `game.rnd()`**：用 `seed + day` 确定性计算，保证同种子下地图与强化卡序列完全不变。
- **不弹窗、不暂停、默认不选择**：不改变 v0.20 的真实时钟与暂停规则；玩家读信息不会被偷时间，也不会被强制做选择。

## 没做的事（说清楚）

- 夜战「建好塔就挂机」的操作深度，这轮只加了一个主动号令缓解，**没有根治**。
- 白天 35 秒是否形成真正的取舍、首日宽限是否够读界面，仍是审查报告里标注的「待真人试玩」，本轮未动任何试玩数值。
- 手机竖屏军令按钮 40px，未达 44pt 通用触摸命中标准；触屏手感待真机验证。
- 跨局战绩只在本浏览器有效，换设备 / 清缓存会重置；没有账号、排行榜或云端。
- 未做真人完整五夜通关、真机触屏实测，也没有任何留存 / 付费数据可引用。

## 下一步建议

1. 手机实跑一遍，重点看：军令按钮会不会太小、常驻浮层会不会挡视线、号令齐射有没有爽点。
2. 找 3–5 个没玩过的人做 10 分钟出声思维测试，只观察三件事：首局 60 秒内能否自己建出城、第一次输能不能说清死因、第一次建营在第几天。
3. 若实跑后仍觉得「每夜都一样」，下一步该动的是夜战节奏（波次变奏、可预告的夜间事件），而不是继续加 UI。
