## 0. 一句话目标与设计支柱

把"领主升级"从数字上涨改造成**一场有名字、有赌性、有仪式的凡人蜕变**，让玩家自愿多打一波、多坐一局。

三条支柱（所有细节为它们服务，冲突时按此裁决）：

1. **成长有名字**：进度条翻译成人话（境界），永远看得见"就差一点点"。
2. **突破是赌局**：赌感来自开奖方差 + 押注重量 + 根基决策，不来自"可能永久变弱"。
3. **失败不毁局**：失败扣进度、扣押注，但基础成长不断、恢复有阀，15→20 波的会话里任何惩罚都不能让这一局"废掉"。

## 2. 境界与节奏

### 2.1 境界映射（领主等级 → 境界）

| 境界 | 等级 | 小阶段（初/中/后/圆满） | 技能池 |
| --- | --- | --- | --- |
| 炼气 | Lv1-4 | 每级一档 | 旋风飞刃、烈焰剑波 |
| 筑基 | Lv5-9 | 每级一档 | + 天雷轰顶、冰霜新星 |
| 金丹 | Lv10-14 | 每级一档 | + 重锤震地、狂战血怒 |
| 元婴 | Lv15-19 | 每级一档 | 全池 |
| 化神 | Lv20+ | 无尽延伸 | 全池 |

- 经验条改称**修为**，常驻显示"距【金丹】还差 87 修为"。
- 技能池按境界闸：突破那一刻池子变大 = 看得见的质变，同时分层喂认知负担。
- 小升级（每级）仍走现有三选一技能弹窗；**大境界门槛走渡劫仪式**（§4），两者视觉档位拉开。

### 2.2 主线节奏拉长

- 主线 **15 波 → 20 波**，Boss 波 5 / 10 / 15 / 20（20 波用强化版毁灭泰坦或新 Boss，待定）。
- 四次境界门槛 Lv5/10/15/20，经验曲线调到门槛落在 **Boss 波前一波**（≈第 4/9/14/19 波），形成"刚渡劫就斩 Boss"的节拍。
- 目标单局时长 ~20-25 分钟。**时长与赌感互相放大**：局越长，押上去的沉没成本越厚，渡劫越心跳。
- 无尽模式顺延至 21+ 波。

## 3. 商店档位（突破接回抽塔循环）

原则：**突破是加速器，不是闸门**。基线跟波数走，谁都不亏；成功只是提前享受。

| 档位 | 基线解锁 | 内容 |
| --- | --- | --- |
| T1 | 第 1-4 波 | 现有 1★ 塔牌 |
| T2 | 第 5-9 波 | 1★ + 2★ 直售牌（约 2× 造价），传说构装权重上升 |
| T3 | 第 10+ 波 | 2★/3★ 直售牌，传说权重再升 |

- **渡劫成功（任意档）= 商店立刻跳一档 + 一次免费高级刷新**（可超前于波数基线）。
- **渡劫成功同时重置刷新费回 5**（偷一念"突破重置每日次数"：突破刷新经济上限，特权再 +1，成本一行逻辑）。
- 失败 = 商店留在波数基线、刷新费不重置，无额外损失。
- 2★/3★ 直售牌省去后期凑对合星的垃圾时间，兼治"后期塔沦为羁绊挂件"。

## 4. 渡劫三档（同一条风险光谱的三个刻度）

UI 形态：一个**押注槽（可空）+ 稳妥/强行开关**，不增加认知负担。

| | 稳妥渡劫 | 空手强行 | 押注强行 |
| --- | --- | --- | --- |
| 成功率 | 100% | 75%（护法丹堆至 95%） | 75% + 押注加成（封顶 90%，丹药至 95%） |
| 押注 | 无 | 无 | 自选 1 件构装（可押备件，可梭哈核心件） |
| 开奖权重（人道/地道/天道） | 85 / 14 / 1 | 70 / 25 / 5 | 70 / 25 / 5 + 根基加成 |
| 失败代价 | — | 修为条 -20% + 道心 +1 | **押注构装损毁** + 道心 +1 + 修为条 -20% |

- 空手档兜底新手（第 4 波首次渡劫时可能只有一两件甚至零件构装）。
- 押注槽对"这是你唯一构装"给红字警告，但**允许梭哈，不拦**。
- 押注件成功则原样返还 + 开奖奖励；失败则损毁（恢复阀见 §7）。
- 渡劫时机玩家自选：备战期按钮点亮；**战斗中修为满也可点开**（复用现有弹窗队列），波本身就是失败后的恢复阀。
- 自动下波开启时若有渡劫待处理：**暂缓 4 秒 + 提示**，别让玩家在自动模式里错过仪式。

## 5. 根基公式（一个数，四个输入，实时预览）

**根基 → 开奖质量概率**。渡劫按钮旁实时显示"根基：地道 · 天道概率 18%"，换押注件时赔率实时跳动（拉杆时刻）。

| 输入 | 计算 | 上限 |
| --- | --- | --- |
| 修为溢出 | 门槛满后继续攒，0→100% 额外一条 → 天道 +0→15% | 封顶一条额外经验条（防无限憋局） |
| 道心圆满 | 圣堡 + 领主满血状态渡劫 → 天道 +5% | 一次性 |
| 道心层数 | 每层 → 天道 +8% | 建议 +40% 封顶（5 层） |
| 押注品质 | 押注分 → 成功 +3%/分、天道 +2%/分 | 成功 +15% 封顶；天道见总封顶 |

**押注分 = 星级 × 品质系数**（史诗 1，传说 2）：

| 押注件 | 分 | 成功率加成 | 天道加成 |
| --- | --- | --- | --- |
| 1★ 史诗 | 1 | +3% | +2% |
| 3★ 史诗 | 3 | +9% | +6% |
| 3★ 传说 | 6 | +15%（封顶） | +12% |

**天道总概率封顶 50%**：全拉满也五五开，jackpot 永远是 jackpot。
**成功率永远留 ≥5% 真实风险**：押满 + 丹药 = 95%，不到 100%（防"赌博变排队"）。

根基决策 = "现在 5% 天道就渡，还是贪两波溢出堆到 20%？但贪的这两波怪也在涨"——**这个纠结就是赌感本体，且自愿拉长时长**。

## 6. 开奖与保底

### 6.1 成功开奖（三品质）

**鬼谷八荒深化：品质不只决定奖励好坏，更决定改命"选项数 + 品质下限"。** 鬼谷人道/地道/天道筑基分别给 1/3/6 个属性选项——移植成我们的改命候选张数：

- **人道渡劫**：改命**三选一**（普通池，改规则词条，含塔系词条）。
- **地道渡劫**：改命**四选一**（含稀有档词条）。
- **天道渡劫**：改命**六选一**（含史诗档词条，jackpot 体感 = 更多+更好的选择，而非抽象概率）。
- 选项数 3/4/6 为鬼谷参考占位，**具体张数与各品质档池内容留待规划**（见总表 §7）。
- 稳妥档也带 1% 天道梦：赌感从"怕输"变"追大奖"（变量比率奖励）。
- 改命池本身带**升级链 + 协同家族**结构，见 §16。

### 6.2 道心（奖励侧保底，非概率侧）

- 每次失败 +1 层；每层天道 +8%；**成功时清空**。
- **不加成功率**——75% 永远是真的 75%，张力保留。
- 失败的心理翻译："这次失败是在给下次天道筑基垫刀"。

## 7. 失败与恢复

- 失败惩罚见 §4。**底线：不掉级、不掉非押注装备、不加战斗 debuff**。
- 修为条 -20% ≈ 半波经验，下一波怪海自然灌满，缺口自愈。
- **补天丹恢复阀**：押注件损毁后，**未来 2 波内商店必刷出一颗补天丹**（时机随机、出现保底），可重塑最近损毁的构装。
  - 损失真实（当下战力缺口 + 金币大出血），恢复确定可买（不会"毁了永远刷不到 = 局废"）。
- **回退旋钮**：若试玩出现"首次毁件即退局"，把"损毁"改为"降 1 星"（3★→2★），赌感保留大半、痛感减半。先按损毁做，数据说话。

## 8. 丹药经济（商店丹药位）

- 商店每次刷新 **25% 概率**带一个丹药位（补天丹保底规则优先）。
- 三种丹（均为金币消耗口，兼治后期通胀）：

| 丹药 | 效果 | 备注 |
| --- | --- | --- |
| 护法丹 | 渡劫成功率 +10%/颗 | 封顶 95% |
| 修为丹 | 直接灌修为/溢出 | 给"憋根基"多一条金币换时间的路 |
| 补天丹 | 重塑最近损毁构装 | 仅损毁后出现；2 波保底；价格 ≈ 原件估值 ×1.5 |

- 原件估值 = 品质基数（史诗 20 / 传说 40）× 星级（起点值，可调）。

## 9. 防死亡螺旋三护栏（不可动摇）

1. **基础成长不受突破影响**：等级/技能/塔/构装照常涨，突破给的是额外奖励层。失败延迟奖励，不掐断成长。
2. **怪物照波数变强**（1.26^w 不动）：冻结怪物会断锯齿曲线、生出"故意失败压难度"的退化策略。螺旋根源是失败造成的实力缺口，缺口已被 §7 堵住，而非怪强。
3. **失败只扣进度与押注，不扣已到手的非押注实力**。

## 10. 表现与仪式

- 境界突破 = 金色渡劫横幅 + 全屏雷劫特效 + 领主外观变档（光环颜色/体型/称号），与日常升级弹窗视觉档位拉开。
- 天道渡劫 = 最高档演出（待定具体特效）。
- 押注槽换件 → 根基预览赔率实时跳动。
- 失败 = 雷劫劈下演出 + 道心层数点亮（把失败演成"垫刀"而非"惩罚"）。
- 复用 v0.51 已有 juice：震屏/金环/飘字/合成音效。

## 12. 试玩验证计划

- **赌感成立？** 押注选择分布：核心件 / 备件 / 空手三档是否都有人用；若一边倒 → 调押注曲线斜率（防 Dominant strategy）。
- **失败不毁局？** 首次毁件后 1 波内的退局率；过高 → 启用"降 1 星"回退旋钮。
- **时长与节拍？** 单局时长分布、境界门槛 vs Boss 波的实际落点、清怪耗时曲线是否保持锯齿。
- **经济？** 丹药支出 / 金币收入比；刷新费通胀是否被丹药口吃掉。
- **天道体感？** 天道实际命中率与玩家"差一点"主观反馈是否匹配。

## 15. 组合技系统（v0.52 范围已定）

来源：《我功夫特牛》配方型 + 《杀戮尖塔》引擎型杂交。**首版只取配方层 + 专精词条**，引擎层进 §14 backlog。

### 15.1 首版范围

4 条配方组合技（领主技能组合，复用现有战斗函数，不加新底层动词）：

| 组合技 | 配方 | 效果 |
| --- | --- | --- |
| 冰刃风暴 | 冰霜新星 + 旋风飞刃 | 飞刃命中附带减速 + 碎冰真伤 |
| 雷火劫 | 天雷轰顶 + 烈焰剑波 | 剑波命中引连锁闪电 |
| 崩山血怒 | 重锤震地 + 狂战血怒 | 震地按已损生命增伤 + 吸血 |
| 万剑诀 | 旋风飞刃 + 烈焰剑波 | 飞刃周期性齐射剑波 |

- **专精词条**（改命池新增，偷尖塔"精简=强度"）：只主升一个技能时其效果 ×2，造"专精窄深 vs 广浅"流派抉择。

- 触发门槛：拥有两件即激活（倾向，低挫败）vs 双双 Lv3。
- 发现层：境界闸图鉴（倾向，接脊柱：炼气无 / 筑基开前两条 / 金丹开后两条）vs 开局全可见 vs 跨局永久图鉴。
- 数量：首版 4 条（倾向）vs 6 条全覆盖。

### 15.3 明确不进首版

- 引擎层（翻转关键词 + 叠层引擎）→ §14。
- UGC 自创组合上传分享 → §14 远期留档。

## 16. 改命词条池设计（鬼谷八荒吸收）

来源：鬼谷"逆天改命"。改命不是孤立词条，而是有结构的 build 骨架。三层设计：

### 16.1 升级链（入门→进阶→精通）

- 同族词条重复抽到 → **升级而非新增占格**（鬼谷武法入门→武法进阶→武法精通；小李飞剑→中李→大李）。
- 造"凑满一族"的跨突破目标：玩家会为了把某族升满而连续押注同方向，强化流派身份。
- 占用有限改命格（格数随境界解锁，接 REALMS）。
- **首版可先做静态词条，升级链作为二期深化**（具体内容/级数留待规划）。

### 16.2 协同家族（与技能/组合技/元素联动）

- 词条按流派家族打标签，效果与本家技能/组合技/元素羁绊共振（鬼谷"玩火三件套"杀心骤起+地火明夷+四灵共生的移植思路）：
  - 火系族 ↔ firewave / 雷火劫 / fire 羁绊
  - 剑系族 ↔ blades / 万剑诀 / wind 羁绊
  - 雷系族 ↔ thunder / 雷火劫 / thunder 羁绊
  - 体修族 ↔ stomp / berserk / 崩山血怒
- 让"改命 + 技能 + 组合技 + 元素"四者拧成一股，而非各刷各的。

### 16.3 选项数随品质（接 §6.1）

- 人道三选一 / 地道四选一 / 天道六选一，高品质档池含稀有/史诗词条。
- 天道体感 = 更多+更好的选择（可见 agency），不靠隐藏概率。

### 16.4 词条分类参照（鬼谷/3DM）

- 伤害类（自动型/触发型）、防护类（常驻/濒死触发）、**特殊类（流派核心，最高优先）**、无用类（不做）。
- 设计原则：每个家族至少一条"特殊类核心"定义流派方向；防护类常驻与濒死触发互斥（常驻减伤会降低濒死触发收益），避免自相矛盾的词条。

> 实现挂钩：新增 PERKS 常量（family / level / 品质档 / 效果函数）；改命弹窗复用 `queueModal`/`renderLevelUpModal` 式三选一框架，按品质出 N 张；效果接 `getHeroStats`/COMBOS/元素羁绊。所有数值留待规划。
