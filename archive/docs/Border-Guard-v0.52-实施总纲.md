> **大地图自由游走割草 × 随身御剑法宝合星羁绊 × 修仙境界渡劫赌局 × 组合技与逆天改命。**

## 2. 核心骨架重构与代码改向清单

### 2.1 无障碍大地图、相机、输入与性能预算
- **世界尺寸**：`W = 64, H = 48, CELL = 44`（`2816 × 2112 px`，3072 格，面积为 v0.51 的 8 倍），无中心圣堡与塔基阻挡。
- **相机跟随与缩放**：`cam.zoom` 按视口自动适配为固定视野窗 `clamp(min(availW / (24*CELL), availH / (16*CELL)), 0.72, 1.15)`（始终保持约 `24×16` 格的可视战术视野，不做滚轮自由缩放，确保不同屏幕压迫感一致）；相机中心采用指数平滑插值 `cam.x += (targetX - cam.x) * (1 - Math.exp(-8.5 * dt))`，边界钳制在 `[viewW/2, W*CELL - viewW/2]`（视口大于地图时居中）。
- **世界坐标输入**：鼠标按住走位与点击实时用当前帧 `cam.x / cam.y / cam.zoom` 换算世界坐标，避免相机移动时指针脱靶。
- **视口裁剪与 60fps 性能预算（140 怪满屏）**：
  - 地表网格、古阵纹路与静态非碰撞地标（预生成表）严格按可见视口 AABB `[camLeft-1 .. camRight+1, camTop-1 .. camBottom+1]` 裁剪绘制，**禁止每帧遍历 3072 格**；
  - 软上限封顶与不卡波规则：同时活跃 `enemies <= 145`、`projectiles <= 220`、`floats <= 60`、`rings <= 45`。当场上活跃怪达到 `145` 时，主队列剩余怪暂停出队，一旦击杀降回 `< 145` 立即继续出队；Boss 召怪遇上限直接跳过不阻塞主队列；**波末判定始终为「主队列全部出队 且 场上敌人 `=== 0`」**，确保永不卡波。
- **刷怪机制（动态视野外圈，绝不屏内凭空刷怪）**：怪物围绕领主当前真实视口外圈刷出——半轴按当前视口动态计算 `rx = max(11.5, viewHalfW + 1.5)`、`ry = max(8.5, viewHalfH + 1.5)`（再钳制在世界结界 `[0.8, W-0.8] × [0.8, H-0.8]` 内），无论窄屏还是超宽屏均保证从屏外四面涌来并直接追击领主。
- **大地图边缘箭头**：屏幕边缘渲染方向指示箭头（红=Boss、紫=精英、金=波中待拾取宝箱，供玩家波中提前吃装提升即时战力；波末依然自动全图吸光剩余经验球与宝箱）。

## 4. 渡劫赌局、根基赔率、道心保底与丹药经济

### 4.1 渡劫三档
| 选项 | 成功率 | 押注 | 开奖基础权重（人/地/天） | 失败代价 |
| :--- | :--- | :--- | :--- | :--- |
| **稳妥渡劫** | `100%` | 无 | `85 / 14 / 1` | 无 |
| **空手强行** | `75%`（丹至 `95%`） | 无 | `70 / 25 / 5` + 根基 | 溢出清零 + 当前修为条 `-20%`；**道心 +1** |
| **押注强行** | `75%` + `min(15%, 押注分×3%)`（含丹封顶 `95%`） | 自选 1 件构装（领主槽或背包） | `70 / 25 / 5` + 根基 | **押注构装损毁** + 溢出清零 + 修为 `-20%`；**道心 +1** |

- 押注构装成功原样保留，仅失败损毁；唯一构装给红字警告但允许梭哈。
- **押注分** = 星级 × 品质系数（史诗 `1`、传说 `2`，范围 `1–6` 分）。

### 4.2 根基公式（实时跳动预览，统一阈值）
- **修为溢出**：`0–100%` → 天道 `+0% ~ +15%`。
- **道心圆满（统一阈值）**：渡劫瞬间领主血量 **`≥ 90% maxHp`** → 天道 `+5%`。
- **道心层数**：每次失败 `+1` 层，每层天道 `+8%`（封顶 5 层 `+40%`），成功清空；**不加成功率**。
- **押注品质**：每分成功率 `+3%`（封顶 `+15%`）、天道 `+2%`（最高 `+12%`）。
- **护法丹**：每颗本次渡劫成功率 `+10%`（叠加至总封顶 `95%`），成败均消耗。
- **天道总封顶 `50%`**；地道 `= min(100% - 天道, 25% + round((天道 - 5%) * 0.4))`；剩余归人道。

### 4.3 商店档位跳档与丹药位（复用商店第 4 槽）
- **基线**：T1（W1–4：100% 1★）→ T2（W5–9：75% 1★ + 25% 2★ 直售 `1.9×`）→ T3（W10+：45% 1★ + 45% 2★ + 10% 3★ 直售 `3.6×`）。
